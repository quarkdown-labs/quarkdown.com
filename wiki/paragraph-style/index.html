    Paragraph style

    The .paragraphstyle docs ↗ function allows you to override the global style of paragraphs.

    All parameters are optional, and if left unset, they delegate their value to the active theme.

    ParameterDescriptionAccepts
    lineheightWhitespace between lines, multiplied by the font size.Number
    letterspacingWhitespace between letters, multiplied by the font size.Number
    spacingWhitespace between subsequent paragraphs, multiplied by the font size.Number
    indentWhitespace at the start of each non-first paragraph, multiplied by the font size.Number

    Using spacing:{0} indent:{2} produces the classic LaTeX look.

    Example 1

    .paragraphstyle lineheight:{2.5} spacing:{0} indent:{2}

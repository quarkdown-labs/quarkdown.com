Line

class Line(source: CharSequence, val start: Int, val end: Int, val nextStart: Int)

A single line of a scanned source, with its indentation precomputed. Lines are produced once per source by Lines.of and never re-sliced.

Parameters

source

the whole source the line belongs to

start

index of the line's first character within source

end

index just past the line's last character, line terminator excluded

nextStart

index of the next line's first character, or end at the end of input

object CodeSpanRecognizer : InlineRecognizer

Recognizes an inline fragment of code. The opening and closing runs must have the same length, and neither may be extended by a further backtick, which is what lets a longer run wrap a shorter one.

object CriticalContentRecognizer : InlineRecognizer

DelimiterRunRecognizer
Link copied to clipboard
object DelimiterRunRecognizer : InlineRecognizer

Recognizes a delimiter run of asterisks, underscores or tildes. It claims the whole run without deciding anything: pairing needs the rest of the line, so it happens in the inline scanner's second pass, and a run that pairs with nothing ends up as plain text.

LineBreakRecognizer

object LineBreakRecognizer : InlineRecognizer

Recognizes a line break that is not at the end of a paragraph. A break preceded by two or more spaces or by a backslash is hard; any other is soft. A newline followed only by whitespace up to a line end is not a break at all, so the padding newline never is one.

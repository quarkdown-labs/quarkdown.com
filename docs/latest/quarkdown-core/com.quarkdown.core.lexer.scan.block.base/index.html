Recognizes a comment, at a line start or in the middle of a line the scan resumed inside. A comment may span lines and absorbs nothing after its closing delimiter, so its text is not line-aligned and its match carries an explicit end index.

FencedCodeRecognizer
Link copied to clipboard
object FencedCodeRecognizer : BlockRecognizer

Recognizes content fenced by three or more backticks or tildes. The block ends at the first line that holds nothing but a run of the same character, at least as long as the opening one, and trailing whitespace. A longer opening fence therefore wraps shorter fences as content, and a block whose fence is never closed runs to the end of the document.

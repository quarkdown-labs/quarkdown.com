Spread

@Target(allowedTargets = [AnnotationTarget.VALUE_PARAMETER])
annotation class Spread

Marks a parameter of a QFunction as a spread of a class type: the processor unpacks the class's primary-constructor parameters into individual wrapper parameters and reconstructs an instance at the delegation call site via named-argument constructor invocation.

@Name on a component of the spread class is honored the same way it is on top-level @QFunction parameters, so exported names are consistent across the wrapper regardless of whether a parameter came from the source function directly or from a spread component.

Example:

data class Style(
    @Name("foreground") val foregroundColor: String,
    @Name("background") val backgroundColor: String = "white",
)

@QFunction
fun container(text: String, @Spread style: Style) = ...

The agent skill shipped in Quarkdown 2.1, aiming at making it easier for agents to write correct and idiomatic Quarkdown.

If you already have the CLI installed, wiring it up to Claude Code is one line:

```bash
ln -s "$(quarkdown doctor get agent-skill)" ~/.claude/skills/quarkdown
```

## How it works

The skill is a `SKILL.md` file bundled with the Quarkdown distribution. When the agent loads it, it picks up on a few key points:

- Quarkdown ships with an offline copy of its own wiki and API reference. The skill points the agent to them, thanks to the `quarkdown doctor get install-dir` command, which returns the path to the installation directory.
- Given a problem, the agent scans the wiki's table of contents to orient, then pull the wiki pages for what's relevant.
- Types and enum values are looked up on demand from the API reference, to cut down on compilation errors from hallucinated values.

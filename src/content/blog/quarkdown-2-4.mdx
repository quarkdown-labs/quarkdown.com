2.4 marks one of the most impactful releases Quarkdown has ever faced, with the core concept being: "you can now extend Markdown itself."
Similar to Typst's `#show` rules, you can think of it as CSS that rewrites the AST, written in Quarkdown itself.

> For more detailed and up-to-date information, check out the [wiki page](https://quarkdown.com/wiki/element-styling) on element styling.

## Primitives

Several Markdown elements now have a matching function behind them, called a *primitive*:

- `.heading` backs `#`, `##`, ...
- `.paragraph` backs plain paragraphs
- `.link` backs `[label](url)`
- `.math` backs `$ ... $` and `$$$ ... $$$`
- `.image` and `.figure` back `![label](url)`
- `.pagebreak` backs `<<<`

Most of them also inherit `.container`'s styling options, such as `foreground`, `background`, `border`, `padding` and `fontsize`.

## Extending a primitive

`.extend` was first introduced in 2.2. Because this release directly binds Markdown elements to their primitives, `.extend` on primitive functions allows intercepting and overriding the default behavior of Markdown elements.

```markdown
.extend {heading}
    content:
    .super foreground:{blue}
        *.content*

## A section heading
```

<div class="result">
  <div class="h2" style="color: #4a9eff; font-style: italic;">A section heading</div>
</div>

The previous snippet restyles every heading in the document to have blue text and italics, by calling `.super` — the original function — called with the overridden arguments.

## Conditional extension

The new `where` parameter lets a wrapper fall through to the original when a condition isn't met. 
The following snippet styles H1 and H2 to have blue text, while H3 and lower headings remain unaffected:

```markdown
.extend {heading} where:{depth: .depth::islower than:{3}}
    .super foreground:{blue}

# Top-level heading
## Section heading
### Subsection heading
```

<div class="result">
  <div class="h1" style="color: #4a9eff;">Top-level heading</div>
  <div class="h2" style="color: #4a9eff;">Section heading</div>
  <div class="h3">Subsection heading</div>
</div>

The following snippet adds an external-link icon to every link that isn't internal (doesn't start with `https://quarkdown.com`):

```markdown
.extend {link} where:{url: .url::startswith {https://quarkdown.com}::not}
    content:
    .super
        .content .icon {box-arrow-up-right}

Check out the [wiki](https://quarkdown.com/wiki)
and the [repo](https://github.com/iamgio/quarkdown) to get started.
```

<div class="result">
  <p>
    Check out the <a href="https://quarkdown.com/wiki" style="text-decoration: none;">wiki</a>
    and the <a href="https://github.com/iamgio/quarkdown" style="text-decoration: none;">repo <Icon name="box-arrow-up-right" /></a>
    to get started.
  </p>
</div>

## Matching against patterns

`.match` scans inline content for regex hits and replaces each one with the output of a lambda:

```markdown
.match {Quarkdown takes its name from quarks} pattern:{[Qq]uark(down|s)?}
    ***.1***
```

<div class="result">
  <p><em><strong>Quarkdown</strong></em> takes its name from <em><strong>quarks</strong></em></p>
</div>

Pair it with paragraph extension to highlight every occurrence of a pattern across the document:

```markdown
.extend {paragraph}
    content:
    .super
        .content::match {[Qq]uark(down|s)?}
            ***.1***

Quarkdown is a typesetting system that borrows its name from quarks,
which are elementary particles in physics and include:
up quarks, down quarks, strange quarks, charm quarks,
top quarks and bottom quarks.
```

<div class="result">
  <p><em><strong>Quarkdown</strong></em> is a typesetting system that borrows its name from <em><strong>quarks</strong></em>,
  which are elementary particles in physics and include: up <em><strong>quarks</strong></em>, down <em><strong>quarks</strong></em>, strange <em><strong>quarks</strong></em>, charm <em><strong>quarks</strong></em>, top <em><strong>quarks</strong></em> and bottom <em><strong>quarks</strong></em>.</p>
</div>

## Status

Primitive extension ships as slightly experimental with a deliberately small set of primitives. The plan is for every Markdown element to eventually be backed by a primitive, if this feature proves stable.

Any feedback, bug reports and enhancement requests are welcome via [issues](https://github.com/iamgio/quarkdown/issues).
